# 依赖图模块文档

## 概述

依赖图模块用于可视化显示戴森球计划游戏中物品之间的依赖关系（原料 -> 产物）。布局方向为从上到下，源节点（原材料）在上方，汇节点（最终产物）在下方。

## 文件结构

- `src/DependencyGraphPage.jsx` - 依赖图页面主组件
- `src/DependencyGraph.css` - 依赖图样式
- `src/engine/graph-utils.js` - 共享图算法（tarjanSCC、compressToDag、dagTopologicalSort）

## 边方向

边存储方向为 `{from: 产物, to: 原料}`，即从产物指向原料。

构建邻接关系时交换赋值，使 `parents` 语义为上游原料、`children` 语义为下游产物，拓扑排序和布局代码的语义不变。

选择此方向的原因：仅需求模式的 BFS 过滤需要从需求物品向上追溯原料，直接用 `from→to` 方向即可，无需建反向邻接表。

## 功能特性

### 1. 依赖关系展示
- 根据当前配方选择显示物品间的依赖关系
- 引线从原料指向产物（下方出，上方进）
- 起点使用蓝色实心圆点标记（出节点/原料端）
- 终点使用黑色实心圆点标记（入节点/产物端）
- 引线绕行算法：当引线经过非目标节点时，自动就近避让绕行
- **自环引线**：自依赖物品（如 X射线裂解中的氢）的引线从底部出线口出，绕左侧画贝塞尔曲线回到顶部进线口
- **循环组内引线**：源节点在循环组内时使用上出点（偏右），目标节点在循环组内时使用上左入点（偏左），控制点根据水平距离动态偏移（5-60px，距离越远偏移越大）；自环边使用下出点和正上方入点

### 2. 布局算法
- **SCC 分析**：使用 Tarjan 算法识别强连通分量，将循环依赖节点分组（输出逆拓扑序：`sccGroups[0]`=最终产物）
- **DAG 压缩**：`compressToDag` 将 SCC 压缩为 DAG 超级节点
- **DAG 拓扑排序**：`dagTopologicalSort` 使用 Kahn 算法（入度=0 先出队），确定 SCC 超级节点的层级
- **循环组层级调整**：多节点 SCC +2 偏移，避免挤占原矿顶层
- **下移优化**：按 SCC 逆拓扑序（产物在前），尝试增大层级直到遇到产物同层
- **重心法优化**：直接决定节点的x绝对位置（理想位置=父节点平均x），重叠时使用重叠组紧密排列算法
- **动态层间间距**：根据每层的引线密度动态调整层间间距（90px-135px）
- **首层默认排序**：首层节点按指定矿石顺序排列（铜矿、铁矿、石矿、硅矿、原油、煤矿、钛矿）

### 3. 交互功能
- **缩放**：鼠标滚轮缩放
- **拖拽画布**：左键拖拽空白区域平移画布
- **拖拽节点**：左键拖拽**首层节点**调整位置（非首层节点不可拖动）
- **右键删除**：右键点击节点删除物品
- **恢复物品**：点击"已删除"按钮恢复物品
- **悬停高亮**：鼠标悬停节点时高亮：
  - 直接上下游节点及连接到悬停物品的引线
  - 直接原料之间的引线（如果有上下游关系）
- **图例高亮**：鼠标悬停图例项时只高亮对应类型的所有物品图标（引线淡化，不高亮），图例分三类：原矿、中间、最终
- **增产剂引线隐藏**：当存在增产剂消耗时，点击"隐藏增产剂线"按钮可隐藏因为使用增产剂（增产或加速模式）而添加的边
- **显示模式切换**：当需求表有物品时，点击"全部配方"/"仅需求"按钮切换显示模式
- **视角居中**：点击"视角居中"按钮恢复默认视角（scale=1, pan={x:0, y:0}）
- **自动居中**：每次切换到依赖图页面时自动居中视角（基于首层节点中心位置）
- **浏览器缩放**：浏览器缩放比例改变后自动重置视角

### 4. 显示模式
- **默认模式**：优先读取上次保存的模式，否则根据需求表是否有物品决定（有物品→仅需求，无物品→全部配方）
- **全部配方**：显示所有配方
- **仅需求**：只显示需求表相关配方
- **模式持久化**：保存在 localStorage（`dependency_graph_show_needs_only`）

#### 仅需求模式（复用核心计算数据）

直接复用核心计算的输出：
- `engineGraphData.edges` - BFS 构建的边（过滤已删除物品）
- `engineGraphData.proliferatorEdgeKeys` - 增产剂边标记（过滤已删除边）
- `engineGraphData.sccs` - SCC 分组（逆拓扑序，直接复用不过滤）

#### 全部配方模式

使用 `build_dependency_graph()` 函数，遍历所有物品的配方构建全量边数据。显示时从全量数据中过滤已删除物品。

**SCC 计算策略**：SCC 基于完整边集（包括电力边）计算，保持布局稳定。过滤电力边只影响渲染，不影响布局。

**电力依赖**：为所有有设备的配方（`recipe.设施` 存在）自动添加对电力的依赖边，确保其他物品能正确显示对电力的依赖关系。

#### 建边逻辑

遍历每个配方，将配方的所有产物（含副产物）都连接到配方的原料。使用 `recipe_handled` Set（全部配方模式）或 `edge_set`（仅需求模式）避免重复处理。

#### 增产剂消耗

若配方配置了增产模式（加速/增产/接收站透镜/增产分馏）且选择了增产剂等级，增产剂会作为额外原料加入边集合。消耗量由 `global_state.proliferator_price` 决定。

建边时检查 `scheme_data.scheme_for_recipe[recipe_index]` 的 `增产模式` 和 `增产点数`，若有效则将增产剂物品加入原料集合。

#### 自环处理

- **拓扑排序**：`from === to` 的边在邻接构建时跳过，不影响入度，物品正常参与排序
- **引线渲染**：自环边用贝塞尔曲线从底部出线口出，绕左侧回到顶部进线口

## 数据持久化

以下数据保存在 localStorage：
- `dependency_graph_deleted_items` - 已删除物品列表
- `dependency_graph_custom_positions` - 全部配方模式的自定义节点位置
- `dependency_graph_custom_positions_needs` - 仅需求模式的自定义节点位置
- `dependency_graph_show_needs_only` - 显示模式选择

### 自定义位置应用规则

- 自定义位置仅对**首层节点**（`is_first_layer`）生效
- 合并时只覆盖 `x` 坐标（水平方向），`y` 坐标始终使用布局算法的计算值
- 物品离开首层后（如布局变化导致下移），其持久化位置自动失效，由布局算法重新计算
- 这确保了层级变化后物品不会因旧的持久化坐标而渲染到错误位置

## 技术细节

### 布局算法流程
1. Tarjan SCC 分解（输出逆拓扑序：`sccGroups[0]`=最终产物）
2. `compressToDag` 将 SCC 压缩为 DAG
3. `dagTopologicalSort` 计算 DAG 层级（Kahn 算法，入度=0 先出队）
4. 循环组层级调整（多节点 SCC +2 偏移）
5. 下移优化（按 SCC 逆拓扑序，产物在前，尝试增大层级直到遇到产物同层）
6. 物品层级映射
7. 构建邻接关系（自环边跳过）
8. 计算每层引线密度，动态计算层间间距（90px-135px）
9. 首层节点默认排序（铜矿、铁矿、石矿、硅矿、原油、煤矿、钛矿）
10. 初始位置分配
11. 重心法优化（两遍遍历）：
    - 第一遍从上到下：普通节点排布，排除循环节点
    - SCC 中心定位（找空隙放置）
    - SCC 水平排列布局
    - 第二遍从下到上：延迟节点排布，循环组整体推挤
12. 全局检查：确保所有非循环节点不与循环组重叠

### 引线路径生成
- **碰撞检测**：收集所有圆点坐标（按y分层存储），生成检测数组
- **检测方法**：在引线的y坐标范围内，计算引线在检测y处的x坐标，检查与圆点x的最小距离
- **绕行算法**：当检测到碰撞时，根据起点在圆点的左右判断避让方向，生成贝塞尔曲线绕行路径
- **控制点偏移量**：绕行时使用 `Math.min(50, dy / 2)`，普通曲线使用 `Math.min(35, dy / 3)`

### 视角管理
- **页面激活**：每次切换到依赖图页面时自动居中视角（基于首层节点中心位置）
- **浏览器缩放**：缩放比例改变后自动重置视角
- **视角居中**：手动重置视角，不清除自定义位置

## 使用方法

1. 在主页面点击导航栏的"依赖图"按钮进入
2. 鼠标悬停节点高亮其直接上下游节点和引线
3. 右键删除物品，左上角按钮恢复
4. 点击"视角居中"按钮恢复默认视角
5. 点击"全部配方"/"仅需求"按钮切换显示模式

## SCC 集成

### 设计目标

用 Tarjan SCC 算法识别循环依赖节点，压缩为 DAG 后进行拓扑排序和层级计算。

### 共享图算法（graph-utils.js）

`tarjanSCC(items, edges)` 函数：
- 使用 Tarjan 深度优先搜索算法识别强连通分量
- 输出逆拓扑序：`sccGroups[0]`=最终产物，`sccGroups[last]`=原矿
- 单节点 SCC = 普通 DAG 节点
- 多节点 SCC = 循环依赖组（如增产剂自喷、石墨烯/可燃冰/重整精炼环路）

`compressToDag(sccGroups, edges)` 函数：
- 将每个 SCC 视为一个超级节点
- 若 SCC-A 中某节点到 SCC-B 中某节点有边，则 SCC-A → SCC-B 有边
- 返回 `{dagNodes, dagEdges, nodeToScc}`

`dagTopologicalSort(dagNodes, dagEdges)` 函数：
- Kahn 拓扑排序算法
- 入度=0 的节点（原料）先出队
- 返回 `scc_id → 层级` 映射

### 布局算法流程

1. Tarjan SCC 分解（输出逆拓扑序）
2. `compressToDag` 将 SCC 压缩为 DAG
3. `dagTopologicalSort` 计算 DAG 层级
4. 循环组层级调整（多节点 SCC +2 偏移）
5. 下移优化（按 SCC 逆拓扑序，产物在前，尝试增大层级直到遇到产物同层）
6. 物品层级映射
7. 构建邻接关系（自环边跳过）
8. 动态层间距计算
9. 初始位置分配（首层矿石排序）
10. 重心法第一遍（从上到下）：普通节点排布，排除循环节点
11. SCC 中心定位：扫描每层空隙，将 SCC 放在最大空隙中间
12. SCC 水平排列布局（成员水平排列，居中于中心位置）
13. 重心法第二遍（从下到上）：处理延迟节点，包含循环节点的最终位置
    - 延迟节点（循环组上游原料）靠近其子节点（含循环节点）定位
    - 使用循环节点的最终 x 坐标（来自水平排列布局）
    - **循环组整体推挤**：循环组作为固定障碍物，非循环节点会被推挤到循环组两侧
14. 全局检查：确保所有非循环节点不与循环组重叠

### SCC 中心定位策略

SCC 循环组不参与重心法排布，而是在所有普通节点排布完后，通过"找空隙"方式放置：

1. 收集该层已排布的普通节点位置，按 x 排序
2. 计算相邻节点之间的空隙
3. 每个 SCC 放入能容纳其水平排列宽度的最大空隙中间
   - 宽度 = `(成员数 - 1) * MIN_GAP`（节点间距60px）
4. 若没有足够大的空隙，放在最大空隙中间（允许轻微重叠）

### SCC 水平排列布局

- 成员按数组顺序水平排列，居中于中心位置
- 节点间距 = `MIN_GAP`（60px），与普通物品相同
- SCC 分组框包围盒 = 水平排列区域 + 节点半径（NODE_R = 32px）

### SCC 整体推挤算法

在重心法第二遍（从下到上）中，循环组作为固定障碍物处理：

1. **收集包围盒**：SCC 水平布局后，收集每个循环组的包围盒（left, right, y）
2. **虚拟组注入**：在处理延迟节点前，将循环组包围盒作为虚拟组（`is_scc_obstacle: true`）加入组列表
3. **重叠检测**：新节点与循环组障碍物重叠时，推挤到循环组左侧或右侧（选择更近的一边）
   - 检测公式：`node_right > bbox.left && node_left < bbox.right`
   - 其中 `node_right = x + MIN_GAP/2`，`node_left = x - MIN_GAP/2`
4. **合并保护**：循环组障碍物不参与组合并算法，保持完整性
5. **repack_group 保护**：重排组时检查与循环组的重叠，如有重叠则推挤
6. **全局检查**：重心法完成后，检查所有非循环节点是否与循环组重叠，如有则推挤

### 层级管理

- **层级属性**：节点位置的 `layer` 属性直接使用布局算法计算的层级值（`layer_idx`）

### 节点类型

节点只区分三种类型（循环物品不再有特殊边框，由 SCC 分组框标识）：
- **原矿**（绿色边框 `#51cf66`）：入度为 0 的源节点
- **最终产物**（黄色边框 `#ffd43b`）：出度为 0 的汇节点
- **中间产物**（蓝色边框 `#4a9eff`）：其余所有节点（包括循环物品）

### 循环节点展示

- SCC 超级节点显示为带标题的红色虚线分组框
- 分组编号使用 `#N` 格式（如 "#1"、"#2"）
- 分组编号位于框的左上角（left: 0）
- 框内节点按水平排列
- 分组框有 `pointer-events: none`，不干扰节点交互
- 高亮逻辑：悬停 SCC 内任一节点时，整个分组框高亮

### 调试面板

点击右上角"层级"按钮可查看（显示压缩后的层级值）：
- 每层的物品列表，每个物品显示 DAG 层级（如 `(0)`、`(2)`）和 SCC 组号（如 `[G1]`）
- SCC 循环组的层级、成员数量和成员列表
