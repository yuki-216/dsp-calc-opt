# 设计规格文档

## 项目概述

在现有开源项目 [DSPCalculator/dsp-calc](https://github.com/DSPCalculator/dsp-calc) 基础上，进行功能修剪和新增，实现：
- 基础生产线计算（保留原有功能）
- 燃料计算模块（新增）
- 增产剂自动优化（新增）
- 占地计算系统（新增）

### 技术选型

| 项目 | 选择 | 说明 |
|------|------|------|
| 基础项目 | dsp-calc | 已实现核心计算功能 |
| 框架 | React 19 | UI组件库 |
| 构建 | Vite | 快速开发服务器 |
| 样式 | Bootstrap 5 | UI框架 |
| 求解器 | javascript-lp-solver | 线性规划 |
| 状态 | React Context | 全局状态管理 |

## 核心模块

### 数据加载 (game_data.jsx)

- 加载 Vanilla.json（原版游戏数据）
- 解析配方、物品、设施数据
- 构建物品ID映射表
- GameInfo 类预处理游戏数据
- GlobalState 类封装计算状态

### 计算引擎 (src/engine/)

两段式计算架构，用矩阵求逆替代LP求解器：

```
用户需求 → DAG层级计算 → 单位成本计算 → 结果汇总
  ↓           ↓              ↓            ↓
BFS构建图   SCC检测      系数表+矩阵求逆  资源/设备/电力/占地
  ↓           ↓              ↓            ↓
依赖图      循环组         成本展开      最终结果
```

**关键设计**：
- 系数表追踪成本，`$`前缀区分执行次数
- SCC循环组用矩阵求逆求解，不需要关键物品断开
- 逆生产机制自动抵消多余产物
- 虚拟"解"配方处理多需求

### 配方方案 (scheme_data.jsx)

- 管理配方选择
- 管理增产剂配置
- 管理成本权重

| Result | 结果显示 | result.jsx |
| BatchSetting | 批量预设 | settings.jsx |
| Settings | 设置面板 | settings.jsx |

| Header | 顶部导航 | ui_components.jsx |

### 新计算引擎算法

**三段式计算架构**：

1. **DAG层级计算**：BFS从需求出发构建依赖图，Tarjan SCC检测循环组
2. **单位成本计算**：系数表追踪成本，按SCC顺序展开：
   - 单节点SCC：直接代入依赖方
   - 多节点SCC（循环组）：构建矩阵，求逆求解
3. **按需求量放大**：需求量 × 单位成本 = 总资源消耗

**关键算法**：
- 系数表：`$`前缀区分执行次数，负数表示副产物
- 逆生产：负系数物品已有执行次数时，展开取消成本抵消
- 矩阵求解：直接构建目标矩阵A，单位频率常数项

## 功能模块

### 燃料计算

用户可选择不同燃料，系统自动计算燃料生产需求和发电设备数量。

**燃料数据**：
| 燃料 | 热值(MJ) | 设备 | 限制 |
|------|----------|------|------|
| 煤矿 | 2.16 | 火力发电厂 | 只能增产 |
| 高能石墨 | 5.4 | 火力发电厂 | 只能增产 |
| 液氢燃料棒 | 43.2 | 火力发电厂 | 只能增产 |
| 氘核燃料棒 | 600 | 微型聚变发电站 | 只能增产 |
| 反物质燃料棒 | 7200 | 人造恒星 | 只能加速 |
| 奇异湮灭燃料棒 | 720000 | 人造恒星 | 只能加速 |

**计算逻辑**：
- 电力作为"物品"参与BFS建边和SCC分析
- 燃料配方自动从燃料数据生成
- 增产剂影响：加速模式减少设备数量，增产模式减少燃料需求

### 占地计算系统

根据建筑类型和配方参数计算占地面积。

**占地公式**：

| 建筑类型 | 公式 | 说明 |
|----------|------|------|
| 制造台 | (4n-1) × (3+l/2) | n=设备数量, l=原料+产物种类数 |
| 熔炉 | 3n × (3+l/2) | |
| 原油精炼厂 | 3n × (6+l/2) | |
| 分馏塔 | 5.5 × (4n-1) | |
| 化工厂 | 7n × (4+l/2) | |
| 微型粒子对撞机 | 5n × (9+l/2) | |
| 研究站 | 5×ceil(n/m) × (5+l/2) | m=堆叠数 |
| 宇宙矩阵 | 12 × (5.5×ceil(n/m)) | 特殊公式 |
| 射线接收站 | (8√n-1)² | |
| 人造恒星 | 49 | 固定值 |
| 火力/微型聚变发电 | 28 | 固定值 |

**参数说明**：
- `n` = ceil(设备数量)，进一法取整
- `l` = 原料种类数 + 产物种类数
- `m` = 研究站堆叠数（默认15）

### 增产剂自动优化

支持多种优化目标函数：

| 策略 | 标识 | 目标函数 | 说明 |
|------|------|---------|------|
| 最小电力 | `min_power` | totalEnergyCost | 最小化总耗电（默认） |
| 最小原矿 | `min_raw_ore` | totalRawOre | 最小化原矿消耗总量 |
| 最小占地 | `min_footprint` | totalFootprint | 最小化总占地面积 |

**两阶段优化算法**：
1. **第一阶段：循环组优化** - 在最高等级配置下找出循环组，用坐标下降遍历最优策略
2. **第二阶段：单物品优化** - 基于第一阶段结果，按SCC正序逐个优化

## 项目阶段

### 阶段1：项目理解与有限优化 ✅

**目标**：复制源项目，在不改变核心功能逻辑的前提下，进行结构理解与有限优化。

### 阶段2：燃料计算 ✅

- 添加燃料选项
- 电力作为"产物"加入输出表格
- 默认电力配方在配置区设置
- 支持多电力方案（类似多配方）

### 阶段3：优化 ✅

- 自动寻找最优增产剂配置
- 目标函数：最小化矿物瓶颈比 / 最小电力 / 最小原矿 / 最小占地
- 忽略占地瓶颈

### 阶段4：占地模块 ✅

- 实现各建筑类型的占地计算公式
- 新增"最小占地"优化策略
- 结果面板显示预估占地面积
