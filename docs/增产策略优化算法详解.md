# 增产策略优化算法详解

> 本文档详细描述在 DAG 层级动态变化约束下，寻找全局最优增产策略的递归 DFS 算法。
> 配合 `core-algorithm.md` 第14-15节阅读。

---

## 1. 问题背景

### 1.1 DAG 层级的两层功能

| 功能 | 说明 |
|------|------|
| **遍历顺序** | 按 DAG 顺序（低→高）遍历增产选择，可实现完美剪枝 |
| **计算顺序** | 给单次资源消耗计算提供迭代顺序（上游先算） |

### 1.2 核心矛盾

增产剂本身是物品，有自己的生产链。**选择增产剂 = 添加新的原料依赖**。

规则：`产物DAG层级 > 所有原料的DAG层级`

因此：低 DAG 物品选择了高 DAG 增产剂 → 增产剂层级被拉低 → DAG 结构变化。

```
例：物品a(dag1) 选择 MK2(dag3) 作为增产剂
→ MK2 变成 a 的原料
→ a 的层级变为 dag4（> MK2的dag3）
→ DAG 结构改变
```

这形成了**循环依赖**：遍历顺序依赖 DAG，DAG 依赖增产选择。
而且这种影响**不是迭代收敛的，也不是双向线性的**。

---

## 2. 关键洞察

> **不需要等所有低层级物品都确定，只需要等该物品的所有上游物品确定即可。**

- 优化遵循 DAG 层级顺序的**本质逻辑**：先确定原料的增产策略，再确定产物的
- 这样数学上可以证明与全局最优增产策略相符
- 但"所有低层级物品都确定"是充分条件，不是必要条件
- **上游物品必然在更低层，但更低层的物品不全是上游**——这是包含关系

```
         所有低层级物品
        ┌──────────────┐
        │  上游物品     │  ← 只需要这部分确定
        │  ┌────────┐  │
        │  │        │  │
        └──┤────────┤──┘
           │ 非上游  │
           └────────┘
```

## 3. 三级递进假设

由浅入深，逐步放开约束。

### 基础数据（无增产剂时的 DAG 层级）

```
MK1: dag1（原料：铁矿）
金刚石: dag2（原料：高能石墨 dag1）
MK2: dag3（原料：MK1 dag1 + 金刚石 dag2）
碳纳米管: dag1
MK3: dag4（原料：MK2 dag3 + 碳纳米管 dag1）
```

### 第一层：只能选比自己层级低的增产剂

- DAG 层级**不变**
- 标准从低到高遍历即可
- 任何物品的原料增产策略都先确认了

### 第二层：增产剂产线不能用高于自己层级的增产剂

- DAG 层级**变化但无循环组**
- 遍历到 dag1 物品 a：
  - a 选 MK1 → a 变为 dag2 → 先递归处理 MK1 的增产选择
  - a 选 MK2 → a 变为 dag4 → 先递归处理 MK2（MK2 的原料金刚石和 MK1 也要递归处理）
  - a 选 MK3 → 同理
- **递归必然终止**：增产剂产线只能选低级增产剂，不会形成环

### 第三层：完全自由选择（核心算法）

- DAG 层级**变化且可能出现循环组**
- 增产剂产线也可以用高于自己层级的增产剂
- 必然出现增产剂循环组（SCC）
- 需要递归 DFS + 动态 SCC 分析

---

## 4. 核心算法：递归 DFS

### 4.1 选择分类

对于增产方式不受限的物品，有 7 个选择：

```
{无, MK1加速, MK1增产, MK2加速, MK2增产, MK3加速, MK3增产}
```

| 选择类型 | 是否产生新分支 | 处理方式 |
|---------|:------------:|---------|
| 无增产 | 否 | 直接计算 |
| 低级增产剂（< 物品层级） | 否 | 直接计算 |
| 同级加速 ↔ 增产 | 否 | 直接计算，**无需重新 SCC 分析** |
| 高级增产剂（> 物品层级） | **是** | 形成/扩大 SCC，递归处理 |

### 4.2 核心逻辑

```
遍历(item):
    对于 item 的每种增产选择:
        如果选择不产生新的高层级依赖:
            → 直接计算，不触发新分析
        如果选择产生了新的高层级依赖:
            → SCC 分析，找到循环组
            → 循环组中若有外部上游未确定的物料，先递归处理那些物料
            → 外部上游全部确定后，循环组内部全遍历
            → 循环组结果持久化
```

### 4.3 SCC 分析优化

不需要每次选择都重新 SCC 分析：

- **记录**上一步所有物品的 DAG 层级
- **仅当**更高 DAG 物品被拉入更低 DAG 时，触发新的 SCC 分析
- 同级选择（加速 ↔ 增产）不改变依赖关系，跳过分析
- 因为存在递归和返回，DAG 层数也要**动态存储**（回溯时恢复）

### 4.4 自循环处理

自循环（如增产剂自喷）不产生新依赖，用等比数列直接计算：

```
实际产出 = 基础产出 / (1 - 自消耗比例)
```

不触发 SCC 分析。

## 5. 完整模拟

以 MK1(dag1)→MK2(dag3)→MK3(dag4) 为例。

### 场景设定

```
MK1: dag1, 原料: 铁矿
MK2: dag3, 原料: MK1(dag1) + 金刚石(dag2)
MK3: dag4, 原料: MK2(dag3) + 碳纳米管(dag1)
金刚石: dag2, 原料: 高能石墨(dag1)
碳纳米管: dag1
```

遍历指针指向 dag1 的物品 a。

### 第一轮：a 的选择

#### Step 1: a = 无

→ 直接计算，无 DAG 变化。

#### Step 2: a = MK1加速

a 使用了 MK1(dag1)，MK1 层级 ≤ a 的层级，不产生新循环。

但 MK1 现在是 a 的新原料，需要先确定 MK1 的策略。

**进入 MK1：**

| 步骤 | MK1 的选择 | 处理 |
|------|-----------|------|
| 1 | 无 | 直接计算 |
| 2 | MK1加速 | 自循环，直接计算 |
| 3 | MK1增产 | 自循环，直接计算 |
| **4** | **MK2加速** | **MK1 使用了高级 MK2(dag3)** |

**Step 4 关键**：MK1 使用 MK2加速 → SCC 分析

```
SCC #1 = {MK1, MK2}, 共享层级 dag=3
```

**进入循环组 #1**，检查外部上游：
- MK2 的原料**金刚石(dag2)**未确定 → 进入金刚石

**进入金刚石：**

| 步骤 | 金刚石的选择 | 处理 |
|------|------------|------|
| 1 | 无 | 直接计算 |
| **2** | **MK1加速** | MK1 在 SCC 中(dag=3)，金刚石(dag2) 用了高级增产剂 |

**Step 2 关键**：金刚石 使用 MK1(dag3) → SCC 分析

```
SCC #1 扩大 = {MK1, MK2, 金刚石}, 共享层级 dag=2
```

**进入循环组 #1**，检查外部上游：
- 现在没有未确定的外部上游了
- 循环组内已通过递归传入：MK1=MK2加速, 金刚石=MK1加速
- **只剩 MK2 的增产选择未确定**

**遍历 MK2 的选择：**

| 步骤 | MK2 的选择 | 处理 |
|------|-----------|------|
| 1 | 无 | 全确定 → 计算结果 |
| 2 | MK1加速 | 全确定 → 计算结果 |
| 3 | MK1增产 | 全确定 → 计算结果 |
| 4 | MK2加速 | 全确定 → 计算结果 |
| 5 | MK2增产 | 全确定 → 计算结果 |
| **6** | **MK3加速** | MK2 使用了高级 MK3(dag4) |

**Step 6 关键**：MK2 使用 MK3加速 → SCC 分析

```
SCC #1 扩大 = {MK1, MK2, MK3, 金刚石}, 共享层级 dag=2
```

**进入循环组 #1**，检查外部上游：
- MK3 的原料**碳纳米管(dag1)**未确定 → 进入碳纳米管

**进入碳纳米管：**

| 步骤 | 碳纳米管的选择 | 处理 |
|------|--------------|------|
| 1 | 无 | 直接计算 |
| **2** | **MK1加速** | MK1 在 SCC 中(dag=2)，用了高级增产剂 |

**Step 2 关键**：碳纳米管 使用 MK1(dag2) → SCC 分析

```
SCC #1 扩大 = {MK1, MK2, MK3, 金刚石, 碳纳米管}, 共享层级 dag=2
```

**进入循环组 #1**，检查外部上游：
- 没有未确定的外部上游
- 循环组内已确定：MK1=MK2加速, 金刚石=MK1加速, MK2=MK3加速, 碳纳米管=MK1加速
- **全部确认 → 计算得出结果**

| 步骤 | 碳纳米管的选择 | 处理 |
|------|--------------|------|
| 3 | MK1增产 | 同级，无需 SCC 分析，直接计算 |
| 4 | MK2加速 | → SCC → 全确定 → 计算 |
| 5 | MK2增产 | → SCC → 全确定 → 计算 |
| 6 | MK3加速 | → SCC → 全确定 → 计算 |
| 7 | MK3增产 | → SCC → 全确定 → 计算 |

→ 比较 7 个结果，得到**在 {MK1=MK2加速, 金刚石=MK1加速, MK2=MK3加速} 条件下碳纳米管的局部最优**。

> 注意：这是局部最优，因为循环组必须遍历完所有可能才能确定全局最优，此时还不能持久化。

#### 返回上层

```
返回到 {MK1=MK2加速, 金刚石=MK1加速}
MK2 的第7步 MK3增产 → 同理遍历碳纳米管的7种选择
→ 得到 {MK1=MK2加速, 金刚石=MK1加速, MK2=MK3增产} 条件下的碳纳米管最优

MK2 的 7 个选择全部遍历完
→ 比较得到 {MK1=MK2加速, 金刚石=MK1加速} 条件下的 MK2+碳纳米管最优

返回上层
金刚石 第3步 MK1增产 → 同理
金刚石 第4步 MK2加速 → SCC{MK1,MK2,金刚石} → ...同理
金刚石 第5步 MK2增产 → ...同理
金刚石 第6步 MK3加速 → ...同理
金刚石 第7步 MK3增产 → ...同理

金刚石 7 个选择全部遍历完
→ 比较得到 {MK1=MK2加速} 条件下的 金刚石+MK2+碳纳米管最优

返回到 MK1 层
MK1 第5步 MK2增产 → 同理
MK1 第6步 MK3加速 → SCC{MK1,MK3} → ...同理
MK1 第7步 MK3增产 → ...同理

MK1 7 个选择全部遍历完
→ 比较得到 MK1 的全局最优（已持久化）

返回到 a 层
a 的后续选择继续...
```

### 搜索树总览

```
a.无 → 直接计算
a.MK1加速 → 进入MK1
  MK1.无 → 直接
  MK1.MK1加速/增产 → 自循环，直接
  MK1.MK2加速 → SCC{MK1,MK2} → 金刚石未确定
    金刚石.无 → 直接
    金刚石.MK1加速 → SCC{MK1,MK2,金刚石} → 外部上游全确定
      SCC内部遍历MK2:
        MK2.无 → 全确定→计算
        MK2.MK1 → 全确定→计算
        MK2.MK2 → 全确定→计算
        MK2.MK3加速 → SCC扩大{+MK3} → 碳纳米管未确定
          碳纳米管.无 → 全确定→计算
          碳纳米管.MK1加速 → SCC扩大→全确定→计算
          碳纳米管.MK1增产 → 同级→直接计算
          碳纳米管.MK2~MK3 → ...→计算
        MK2.MK3增产 → 同理→碳纳米管遍历→计算
      → 比较MK2全部选择，返回最优
    金刚石.MK1增产 → 同级→直接计算
    金刚石.MK2加速 → SCC{MK1,MK2,金刚石} → ...同理
    金刚石.MK2~MK3 → ...同理
  → 比较金刚石全部选择，返回最优
  MK1.MK2增产 → 同理
  MK1.MK3加速 → SCC{MK1,MK3} → ...同理
  MK1.MK3增产 → 同理
→ 比较MK1全部选择，返回最优
a.MK1增产 → 同级→直接计算
a.MK2~MK3 → ...同理
→ 比较a全部选择，返回全局最优
```

## 6. 持久化与剪枝

### 6.1 持久化的正确性

当一个物品（或循环组）的**所有上游都已确定策略**后，遍历其所有增产选择得到的最优策略可以**永久持久化**。

原因：上游不会再变 → 局部最优 = 全局最优 → 不可推翻。

### 6.2 单 DAG 节点

普通物品（非循环组成员）：所有上游确定后，遍历 7 种选择，最优结果持久化。

### 6.3 循环组（SCC）

循环组外部上游全部确定后，循环组内部全遍历得到的最优策略持久化。

循环组内的物品一旦 resolved，就不再参与后续搜索 → **强大的剪枝**。

### 6.4 剪枝效果

```
增产剂产线在全遍历之后 → 最优策略持久化到全局
→ 得到当前阶段的唯一剪枝
→ 后续搜索不再考虑这些物品
```

## 7. 算法特性

### 7.1 最短路径

> "此算法已经是最短路径，物品使用低级增产剂不会分散出无效的新遍历分支，只讨论发起循环组变化使用高级增产剂的必要分支。"

| 选择类型 | 是否产生新分支 | 计算成本 |
|---------|:------------:|---------|
| 无增产 | 否 | O(1) |
| 低级增产剂 | 否 | O(1) |
| 同级加速↔增产 | 否 | O(1) |
| 高级增产剂 | **是** | 需递归 |

### 7.2 完整性

- **不重复**：同级选择不触发 SCC 分析
- **不遗漏**：SCC 内部全遍历所有组合
- **必然终止**：每次递归要么确定一个物品，要么扩大循环组（有限增长）

### 7.3 缺点

- 递归对变量的正确性要求高
- 递归层级可能很多
- 需要仔细管理状态回溯

### 7.4 复杂度

搜索空间远小于 `7^N`（N 为循环组最大成员数），因为：

1. 大部分物品选低级增产剂（不产生分支）
2. 只有高级选择才展开递归
3. 持久化后不再重复计算
4. 同级选择跳过 SCC 分析
